SYSTEM INFORMATION

The Saint Franck University intranet uses a permanent document history system.

When a document is modified, the previous version is retained in the archive.

Documents marked HIDDEN are not displayed through standard searches.

Documents marked MODIFIED have been replaced by a newer version.

Deleting a document permanently is not supported by this system.
